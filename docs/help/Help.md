# LaserCraft Help

Version 0.25 - physical jobs and homing

## Connected physical workflow

For GRBL 1.1 serial/TCP profiles, selecting Connect establishes the connection and applies that profile's bed dimensions to the current document (an undoable edit, without scaling artwork). Physical X/Y/pulse/line controls are available directly after connection; the repeated enable-control/firing checkboxes are removed. Console custom commands still have their own explicit permission. Simulator profiles remain available for regression rehearsal; physical connections use Review & Run for real output.

Home on Connect is visible and checked by default in this app session for physical GRBL profiles. The button reads Connect + Home when selected. This sends $H after identity/settings checks, not on background port detection. Uncheck it before Connect to query without homing. Home is also a dedicated button. Firmware $22 must report 1; homing can take up to 120 seconds. This establishes the firmware reference and leaves work offsets unchanged. Machine coordinates may remain negative; homing does not silently set G54/G92 or a displayed work 0,0. No automatic unlock or firmware-setting writes occur.

Move jog distance now permits up to the selected profile axis travel (430 mm for your X/Y profile), with feed 60–3000 mm/min. The UI limits the distance field to the larger profile dimension; each axis is checked separately before transmission. These are command-size limits, not current-position clearance guarantees. Start with small moves to verify direction. Pulse and line tests retain preflight settings checks and clearly labeled action buttons/reviews.

## Physical cutouts and image engraving

Create/import artwork, assign typed layers, set speed/power/passes/air and prepare images with the existing grayscale/dithering controls. Preview before running. Review & Run (or Run document) builds an immutable snapshot of enabled layers, respecting selected-only scope. Vectors, fills and processed image scan segments use the same planner as preview/export. The review reports segment count, footprint and ideal time; confirm material, placement, extraction and protection before Run.

Placement in this first streaming mode: CURRENT HEAD anchors the minimum machine X/Y corner of the mapped output bounds. The job extends in +X/+Y. Profile origin transforms canvas geometry first. Initial travel from canvas 0,0 is discarded for placement; scan overscan and remaining travel count toward the footprint. Commands use explicit G53 machine coordinates, so G54/G92 work offsets do not relocate the job. No work offsets, homing settings or firmware settings are written. No return move follows completion. Position the head at the appropriate minimum-X/Y corner over scrap and ensure the entire footprint is clear. This is especially important with reported $20=0 soft limits. Automatic nesting, saved positions, absolute-work-origin selection and physical framing remain future work.

Preflight requires identified GRBL 1.1, fresh Idle/MPos, reported millimetres ($13=0), $32=1/$31=0, and $30/$130/$131 matching the selected profile. The prepared program uses millimetres, absolute coordinates, dynamic M4, configured M7/M8 air and M5/M9 at completion. Streamer sends one line then awaits its terminal reply; throughput can be lower than optimized senders, especially for dense images. Each reply has a 120-second timeout. Progress is lines acknowledged, not measured burn completion. Success requires a final Idle report, not proof of optical output or cut quality.

Pause / Resume sends realtime hold/resume and freezes further dispatch while paused. Abort cancels dispatch and requests Ctrl-X soft reset; abort/errors require reconnect, with no automatic retry/resume. Commands accepted before hold can remain in the planner. A failure also attempts reset, but a broken connection/controller can prevent it. These controls are not hardware emergency stops. Disconnect during a job attempts abort/reset; closing is blocked while a physical job is active. Keep the physical stop/power switch ready and inspect output. New streaming/homing workflows still require hardware qualification despite the successful earlier line test.

The original icon is embedded in the executable/window. Source SVG and the Windows generation script are included in the repository under the project MIT license. No proprietary assets or code were used.

## First supervised line cut / mark test

Use the complete 0.24 portable build. A toolbar reading 0.14 is an older, query-only build; replace the extracted application folder with the new package, keeping all companion files together. Per-user profiles remain under LocalAppData/LaserCraft. Your submitted 0.14 screenshots show successful GRBL identity/status/settings queries, not a motion or cut test.

Connect the actual GRBL 1.1 USB COM profile, with S maximum matching reported $30. Verify unpowered X/Y direction and clearance with small jogs. Position the head over scrap with a clear path in the selected signed direction. Open Move and choose Review line cut test. Select X or Y, signed length, feed and power; read the summary and confirm positioning/protection/physical stop before Run. No command is sent by opening or cancelling the review.

This is one straight pass from CURRENT head position, with no return move, homing or automatic bed fit. Limits: 0.1–20 mm, 60–3000 mm/min and >0–100% power. The default 5 mm / 600 mm/min / 10% is an editable mark/motion example, not a material recipe. For your 5 mm plywood scraps, inspect the mark and qualify settings on scrap; no through-cut guarantee is made. Air state is left unchanged. Do not assume a displayed zero or profile bed establishes a safe position. Your report has $20=0 (soft limits off), $21=1 and $22=1; homing-enabled does not prove that homing occurred.

Preflight requires Idle, sends M5 S0, reads $$ and requires $32=1, $31=0 and $30 matching the profile. It reads $G and requires G21/G90/G94. The bounded four-line program selects incremental millimetres/dynamic M4 with S0, performs one powered G1 axis move, sends M5 S0, then restores G90 G0. All four lines, including off, are queued in one short write before replies are awaited. The test then requires a final Idle report; this is controller-reported completion, not measured physical accuracy or penetration. It leaves G21/G90/G94/G0, M5 S0 and the test feed active. Firmware settings are never changed automatically.

Partial transmission, controller failure or rejected commands can prevent shutdown/mode restoration. Software off/cancel waits behind an exchange; disconnect/closing does not stop hardware. Keep the physical stop/power switch ready, with laser protection, extraction and supervision. On interruption no retry is made; inspect output and save the connection log before reconnecting. Document jobs and realtime controls are described above; hardware emergency control and automated material-test grids remain unimplemented.

Protocol follows [GRBL laser mode](https://github.com/gnea/grbl/wiki/Grbl-v1.1-Laser-Mode) and [GRBL interface responses](https://github.com/gnea/grbl/wiki/Grbl-v1.1-Interface). No proprietary implementation is used.

## Material Library

Open Material Library beside Laser/Help. First apply your edits in Cuts / Layers, then enter a preset name, optional thickness (0 means unspecified) and notes such as laser model/material. Save layer as new captures the active layer's applied settings: speed, power, Line/Fill/Image mode, passes, air assist, interval and image processing. Unapplied inspector fields are not captured. Presets contain no artwork, machine endpoint, S maximum, homing or position settings. No factory recipes are supplied; qualify your own settings on your machine.

Select a preset to review its type/settings and edit its name, thickness or notes. Replace selected saves the entered metadata and the current active layer's settings under the selected preset's identity. It replaces settings as well as metadata. Save layer as new creates a separate preset. Duplicate names are allowed. Delete selected asks for confirmation and leaves projects unchanged. Library changes are saved immediately and are separate from project Undo.

Choose the target row in Cuts / Layers, return to the library and click Apply to active layer. Image recipes require an Image layer; vector recipes require a Vector layer. Application changes process settings but preserves the target name/color, output switch, visibility, layer position and artwork associations. It is one project Undo step. Thickness/notes are reference metadata and do not calculate power, focus or passes. Recipes use percentages and are not automatically calibrated for another laser.

The local, versioned materials.json is stored under LocalAppData/LaserCraft, separately from projects and portable binaries. Previous contents are retained as materials.json.bak on each successful replacement; this is one previous revision, not full history. Limits are 500 presets and 2 MB, names 128 characters, notes 2000 characters and optional thickness >0–1000 mm. A malformed/unreadable library disables saving instead of overwriting the original; preserve/repair the file or backup and restart. Import/export, search/categories, per-device binding and automated material-test grids remain planned. Applying/saving recipes sends no laser commands.

## Physical GRBL pulse tests

Connect a physical GRBL 1.1 profile and use Pulse test in Move. Start at 1% / 100 ms over suitable scrap with protection and physical stop ready. Limit remains 5% / 500 ms. Preflight requires Idle and $32=1/$31=0/$30 matching profile S maximum. Controller-side dwell and M5 are queued together; partial transmission/controller faults can prevent off. Nominal dwell is not optical duration. G1/G94/F60 remain active afterward. Laser off queues M5 S0; Cancel jog sends 0x85. These manual actions wait for any current exchange and are not emergency stops. Document-job Abort has a separate realtime reset path.

## Select artwork with a box

In Select mode, drag from empty canvas space. Drag left-to-right for a cyan window: only fully enclosed object/group bounds are selected. Drag right-to-left for a green dashed crossing box: visible object bounds touching or overlapping the box are selected. This uses stored rectangular bounds, so empty space inside a path or ellipse frame can match. Images use their full frame, including transparent pixels.

Hold Ctrl when starting to add matches. Hold Alt to select individual visible group members. Otherwise a window must enclose the whole group, including hidden companions; crossing a visible member selects its whole group. Hidden standalone objects are excluded. Check the hidden-member selection count before edits. Selection applies on release after a minimum 3-pixel drag, independently of grid snapping, without an Undo entry. Escape cancels and clears selection. Start over artwork to move/select it instead.

## Group artwork

Select at least two objects and choose Arrange / Group (Ctrl+G). Click a member's outline to select the whole group; drag moves the selected set together. A cyan box marks combined group bounds. Ctrl-click toggles a group. Alt-click selects one member; Ctrl+Alt-click toggles one member. Individual selections allow edits within a group. Arrange / Ungroup (Ctrl+Shift+G) clears the selected groups, including their other members. Group and Ungroup are each one Undo step.

Groups can contain vectors, cached text and images across layers. Normal group selection includes hidden members; the selection label reports their count. Select All starts with visible objects and includes their grouped companions. Check this count before transforming, reassigning or deleting artwork. Images still require dedicated Image layers. Grouping does not merge layers, change cut settings or override layer burn order.

Alignment and distribution use selected group bounds as units, preserving internal offsets. Distribution requires three units. Alt-selected subsets act only on those selected members. Copies/pastes and each rectangular-array cell receive independent group identities. Path conversion, node edits, tracing and text regeneration retain the source object's membership; joining/combining uses the surviving first object's membership. A group may retain one member after deletions or path operations.

Native .lcraft files retain flat group identities. Grouping selected groups merges them into one flat group; nested hierarchy, group names and locking remain planned. Older LaserCraft versions ignore this metadata and lose it when resaving. SVG exports flattened artwork; group metadata does not affect planned output.

## Console commands and firmware settings

Connect to the chosen profile, select Console, type one command and click Submit or press Enter. The transcript shows the attempted TX, returned RX lines and Acknowledged/Rejected/Alarm/Status result. Up/Down recalls up to 100 commands from this connection session. Clear log clears the visible transcript; Save connection log retains the separate bounded transport journal. Input and Submit are disabled while disconnected or another query/command is in progress.

Query mode permits ?, $, $$, $I, $G, $# and $N exactly. For changing GRBL settings, enable Enable setting writes / custom G-code for this connection, then submit the specific assignment, such as $32=1. This checkbox also permits other single-line G-code/system commands, which can move/fire hardware, actuate air or change persistent settings. It resets on disconnect/new Connect and is not saved as a preference. No state-changing command is sent automatically. Settings writes do not update your LaserCraft profile automatically; read $$ afterward to verify the reported value and review the profile where necessary.

One printable ASCII line of 1–79 characters is supported, with a newline appended for ordinary commands. The ? status query is sent as a single byte. Newlines, control/non-ASCII bytes and embedded ?, ! or ~ are rejected even inside comments, because GRBL intercepts real-time characters separately. Hold/resume/reset and firmware-image flashing are not implemented by this input. No multiline programs, macros or job streaming are implied.

The console uses one send/response exchange at a time, sharing the connection gate with diagnostics. It retains push messages until the terminal ok/error/alarm or requested status arrives. ok is acknowledgement, not proof of completed motion, safe positioning or verified settings. Use $$ readback after a setting write. Timeout is 1–120 seconds (default 10). A timeout, cancellation after attempted transmission, restart, malformed/oversized response or lost connection leaves the command outcome uncertain; no retry is performed, and reconnect is required. Disconnect does not cancel motion or turn off a laser. Physical hold/resume/abort and this console are not hardware emergency stops.

The simulator accepts numeric settings $10, $13, $30, $31, $32, $130 and $131 in session memory, with simple range validation; $$ reads them back. $13 also changes its reported position units. These changes disappear on a new simulator connection and do not alter saved profiles. Other custom G-code returns error:20 rather than pretending to model hardware motion. Real GRBL serial/TCP commands are implemented but physical USB behavior is unverified. Guided GRBL Move/pulse controls are described above; broader physical qualification and full production readiness remain unfinished.

## Create and edit text

Choose the left T button or Tools / Create text. Choose an installed font family, Bold/Italic if that style exists, font em height in millimetres, line spacing and curve tolerance. Em height is a font design unit, not the exact visible capital-letter height; the dialog reports actual ink bounds. Enter multiple lines with Return. The initial outlines prepare automatically. After changing values, use Preview text; Create/Update stays disabled until those exact settings have a successful preview. Cancel changes nothing.

This first text engine supports basic Latin/precomposed extended-Latin characters in U+0020–U+024F, excluding controls/format characters. Maximum 512 characters and 32 lines. Tabs, combining sequences, complex scripts, bidirectional shaping, ligatures, kerning controls, rich text, text-on-path and variable text are not implemented. Unsupported characters, missing glyphs, missing font/style, open/empty outlines or excessive geometry fail explicitly; an unavailable font is not silently substituted.

Create inserts one selected text-outline object on the active vector layer, falling back to an existing vector layer if an image layer is active. It is centered on the bed when it fits. Use the main inspector to position/resize it and Cuts / Layers to assign speed, power, Line/Fill, passes and air. A very large text object can extend off-bed; Preview/export retains its existing bounds checks. Creating/updating is one Undo step.

Select exactly one text object and choose Tools / Edit selected text to change its source settings. Editing keeps identity, position, cut layer, mirrors and existing horizontal/vertical resize factors; the new content's natural dimensions are multiplied by those factors. Its top-left ink anchor stays fixed, so a longer edit grows to the right. Blank lines add baseline spacing, but leading/trailing whitespace has no independent selectable bounds.

Native .lcraft saves both source text/settings and cached closed polylines. Reopening, display and output use the saved geometry without requiring that font to be installed. Editing requires the named font/style or an explicit replacement. Fonts are not embedded or distributed. Changing fonts/versions and regenerating can change geometry; inspect the preview. Curve tolerance (0.001–1 mm) applies before later resizing; it is not a physical accuracy guarantee. Existing path-vertex and file-size budgets apply.

Tools / Convert selected to paths removes the text link without changing outlines, making ordinary editable nodes. Node edits, rotation, reversal, close/join/separate/combine operations that replace geometry also remove text editability on affected objects. Undo restores it. Moving, numerical resizing, mirroring, alignment, distribution and copies/arrays keep the text source. SVG export writes outlines rather than editable SVG text. Fill follows the current even-odd rule; overlapping glyphs are not automatically welded. These editing operations send no machine commands. Advanced Console commands are a separate opt-in.

## Arrange artwork

Arrange / Rectangular array repeats the entire selected set as one cell. Rows and Columns are totals including originals, which stay unchanged in the top-left cell. Nonnegative horizontal/vertical gaps are between combined cell bounds; pitch equals cell width/height plus gap. Copies extend right/down. The dialog updates added-object/layer counts and final bounds as values change, and disables Create for invalid or oversized results. A repeated axis with zero-extent artwork needs a nonzero gap.

Vector copies keep their existing cut layers. Every image copy gets a new dedicated layer appended to the list, retaining its source speed, power, passes, air and image-processing settings. Original embedded pixels and mirrors are preserved. Objects are appended cell by cell in row-major order; output still follows the layer list, so a multi-layer cell is not necessarily burned as a unit. Originals and copies are selected afterward. Creation is one Undo step. Cancel leaves artwork unchanged. There is no automatic nesting, overlap removal or bed fitting; off-bed bounds are called out and output preview/export retains its bed checks.

Arrays check the existing project limits before allocating copies: 100000 objects, 256 layers, 128 images, 200000 path vertices and 24 MB of encoded embedded image data. Native saves retain the separate 32 MB file limit. Very dense projects can still be unsuitable for interactive editing or physical output.

Arrange / Distribute requires at least three selected objects or group units. Horizontal/Vertical centers sorts by center and evenly spaces those centers, retaining the two outer center anchors. Horizontal/Vertical gaps sorts by leading edge and gives equal nonnegative edge gaps with the first/last objects fixed. Equal-position ties follow document order. Negative available gaps reject the whole operation; center spacing can overlap differently sized objects. The other coordinate, identity, layer, image data and dimensions are retained. One Undo restores positions.

Arrange / Rotate vectors rotates about the combined selection center, with positive degrees clockwise on the canvas. It accepts finite angles from -360 to 360, excluding zero/full turns. Rectangles become closed paths; ellipses become 128-point polylines; original path contours, holes and direction are retained. Identities and cut layers stay the same. This is sampled vector geometry, not native curve handles or a physical accuracy guarantee. Images in the selection reject the operation; raster rotation remains planned. Undo restores original shape types. No automatic bed fit occurs.

Arrange / Reverse path direction reverses each selected path contour. Open start/end vertices swap; a closed contour keeps its first vertex while traversal reverses. The contour list/object order and cut settings are unchanged. Mirrored paths are supported. Convert rectangles/ellipses to paths first; images must be traced. Fill uses the existing even-odd rule rather than contour direction. Reversal is one Undo step; it does not perform cut-order optimization.

Try samples/arrangement-demo.lcraft (included in the portable package). Ctrl+A selects three rectangles. The default 2 × 3 array creates 18 objects with bounds 370 × 25 mm and a 1080 mm vector cut length. Undo returns to three originals. Horizontal gaps moves the middle rectangle from X55 to X60; then a 90-degree rotation produces combined bounds X75/Y45, 10 × 120 mm. These are editing/preview examples; no machine commands are sent.

## Create layers and control order

New projects start with one vector layer. In Cuts / Layers, choose + Layer, enter a name, and choose Vector or Image. You can optionally assign the current selection when creating it. Each layer has its own name, color, speed, power, passes, output, visibility and air-assist setting. Edit the fields below the list and click Apply cut settings.

Enabled layers run from top to bottom. Select a row and use the up/down buttons to change its job order. Object associations and settings move with the layer. Reordering is undoable. Delete empty removes unused layers; move their objects elsewhere first. At least one layer remains. Existing projects keep their layer lists.

Choose the Layer color button to open a visual picker with palette swatches and red/green/blue sliders. Apply color updates the selected layer and its artwork, and can be undone. Cancel keeps its previous color. Hex entry is no longer required.

To reassign artwork, select objects on the canvas, select the destination layer row, and click Assign selected. Clicking its bottom color swatch also assigns the selection. With no selection, a swatch chooses the drawing layer. Imported SVG geometry uses vector layers, just like drawn shapes. Colors identify job settings; they do not recolor a photograph.

## Separate image layers

An image must have its own Image layer. It cannot share a layer with lines, shapes, SVG vectors or another image. Assignments that violate this rule are rejected without changing the document. Duplicating an image creates another dedicated layer. Vector layers support Line/Fill; image layers use Image mode.

File / Import image accepts PNG, JPEG and BMP. Original encoded bytes are embedded in .lcraft, so reopening does not depend on the source file. Images support selection, movement, numerical resizing, mirroring, copy/duplicate and layer reassignment. They have a colored border showing the assigned layer while their original pixels remain unchanged. Drawing tools switch back to an eligible vector layer.

Select the image or its image layer and choose Image settings…. The dialog compares the original with prepared engraving pixels. Choose Threshold, FloydSteinberg, OrderedBayer (4 x 4), Grayscale, Stucki, Jarvis or Atkinson; adjust brightness, contrast, gamma and inversion. Threshold is enabled only for Threshold mode. Update preview recalculates the sample view; Apply saves the independent settings to that layer. Cancel leaves the project unchanged. Original image bytes remain untouched and undo/redo includes processing settings.

Interval sets a maximum sample spacing in mm; sample counts are rounded upward and evenly cover the full physical image size, so effective DPI may be slightly higher than 25.4 / interval. The dialog reports effective horizontal/vertical DPI. Transparent pixels stay laser-off even when inverted. Partial alpha blends toward white after tone adjustments. Processing uses sRGB-weighted luminance and 8-bit output; no material-response or optical calibration is implied.

Enabled image layers now contribute scanline paths in their list order alongside vector layers. Threshold and dithers map enabled samples to layer power; Grayscale maps sample darkness proportionally from zero to the layer power. Consecutive equal-power cells form runs. White runs are off and all-white rows are skipped. Mirror flags affect sample placement. Bidirectional alternates row direction; turning it off returns to the left for each row. Overscan adds laser-off travel before and after the image; out-of-bed overscan is rejected. Off regions during a row use the layer scan speed; moves between rows use the current ideal 6000 mm/min travel assumption.

Source pixels stay visible behind the path overlay as design context. The prepared image dialog is the monochrome sample view, not a physical burn prediction. SVG export embeds original raster data; tone/dither settings stay in .lcraft. SVG import currently accepts only the vector subset described below.

Limits: 8 MB per imported encoded image; 16000 pixels per dimension; 40 megapixels per original; 128 image objects, 80 megapixels of unique assets and 24 MB of base64 image data per project. Preview textures are limited to 2048 pixels on their longest edge. Projects are limited to 32 MB on disk. Large-image tiling and asset deduplication remain planned.

## Device profiles and connection

Choose Devices… in the Laser panel or Laser Tools menu. Create a named profile and select the controller family, Simulator/Serial/TCP connection, COM port, baud rate, TCP host/port, bed dimensions, origin and S-value maximum. Serial uses 8 data bits, no parity, 1 stop bit and no flow control; DTR/RTS are optional. Opening some serial ports can reset their controller. Profile settings are stored under LocalAppData/LaserCraft/devices.json, separately from projects.

GRBL connects in query mode, with separately enabled manual console writes. grblHAL and FluidNC use an experimental GRBL-compatible adapter. Marlin, Smoothieware, Ruida and Trocen can be saved as profiles but do not yet have connection adapters. Selecting a controller family is not a claim of tested machine compatibility. No Atezr hardware has been tested.

Select a saved profile, then Connect. The application queries firmware identity ($I) and status (?), and optionally homes when Home on Connect is checked. Running a document remains a separate reviewed action. Read status refreshes the report; Disconnect closes the connection. Status coordinates identify MPos or WPos exactly as reported. Missing coordinates stay unknown. A built-in GRBL simulator is the default and works without hardware. Connection cancellation, line limits and response timeouts bound reads; the user has reported successful 0.24 manual line cuts; new homing/document behavior remains unverified.

### Test a GRBL connection

1. Close the connection in LightBurn or other software using the same COM port.
2. Open Devices… / New profile. Choose GRBL and Serial, select the laser's COM port, and use the baud rate specified by its manufacturer (GRBL 1.1 commonly uses 115200). Refresh serial ports rescans the list without opening a port.
3. Set Serial startup delay as needed. The default is 2000 ms after opening the port and before the identity query; 0–10000 ms is supported. Some boards restart on open. DTR and RTS default off; change them only as required for your controller. The delay is a configurable engineering default, not a guarantee for every board.
4. Save the profile, select it in the Laser panel and click Connect. A successful connection displays firmware identity and a reported status such as Idle or Alarm. Read status sends another status query; missing telemetry remains explicitly unknown. Coordinates/feed use reported controller units, which may depend on firmware settings. No work/machine coordinate conversion is inferred.
5. Read firmware settings… queries $$ and opens a selectable, read-only report. It shows the profile's S maximum alongside reported $30, and the raw reported $32 laser-mode value. A differing $30 produces a profile-review message; no controller or profile values are changed. Unknown setting numbers and their original values remain visible. Close the report and Disconnect when finished.

For TCP, choose TCP and supply the controller's configured host and port; the serial startup delay does not apply. Do not use an arbitrary IP or COM port. A timeout or rejection closes the connection; check the endpoint, baud and whether another program owns the port. No reset, unlock or retry command is sent automatically. Profiles are locked against editing/switching while connecting or connected; disconnect first. Read operations are serialized, and Disconnect can cancel an outstanding read.

Status now includes feed, spindle/S, available planner/receive buffers, active pin flags and accessory flags when reported. Missing fields are not fabricated or retained from an earlier frame. Raw status goes to the Console log. Diagnostic buttons issue read-only queries. Console now supports explicit queries and opt-in setting/G-code writes. Review & Run and pause/abort address the physical job when connected; simulator playback is separate. Connected GRBL Move/pulse, Home and reviewed document jobs are implemented; new hardware workflows remain unqualified.

Apply device bed explicitly changes the document dimensions to the selected profile. It does not move a machine. Origin and power range are stored for future job-coordinate/power mapping; the current design model uses a top-left origin. Device profile changes do not silently alter document geometry or cut settings.

## USB setup and connection checks

In Devices, Attzr 35 W USB draft prepares a new unsaved USB serial profile with the user-specified 430 × 430 mm bed. Choose a detected COM port and review all settings before Save profile. Its 115200 baud, S1000, bottom-left origin and air settings are starting values, not independently confirmed manufacturer defaults. Saving does not open the port. Close discards the draft.

For a saved Serial profile, choose USB COM for this connection in the Laser panel. Refresh COM ports after plugging in the machine. This enumerates ports without opening them. A detected port must be explicitly selected; LaserCraft does not try arbitrary ports or sweep baud rates. A changed port selection applies to this connection only and does not overwrite the saved profile. Profile/port selection is locked while connecting or connected. Close other software using that port, then uncheck Home on Connect and use Connect for query-only diagnostics.

Connection check queries firmware settings ($$), parser modes ($G), then status (?). The report compares profile S maximum with $30, laser mode $32, status-report units $13, G-code units/distance/feed/spindle modes, controller state, reported S, and travel vs bed size. Match, Attention and Unknown describe individual comparisons, not permission or readiness to cut. Missing/invalid numeric facts stay unknown. G21 program units and $13 status units are separate facts. Position readouts do not prove homing, usable area, work offsets or origin.

The report includes source responses, endpoint and UTC collection interval. These are sequential readings and may become stale; they are not a continuous or atomic machine state. No controller settings, modes or profile values are changed automatically. Cancelled, malformed or rejected queries disconnect the monitor rather than present a successful report. Connected GRBL Move/pulse controls are directly available; reviewed document jobs are available in Laser.

## Testing a copy on another Windows computer

Use the complete self-contained Windows x64 portable ZIP, extract it locally and start LaserCraft.Desktop.exe. Keep all companion files together. Debug EXE files alone are insufficient. Run on the computer with the USB laser attached; server storage does not forward that USB port. The package includes USB-CONNECTION-TEST.md, BUILD-INFO.json (source/version/runtime) and FILES-SHA256.json (file hashes). Per-user device/settings files remain under LocalAppData/LaserCraft. No driver is bundled or installed.

Save connection log in Laser exports the latest connection attempt as a text snapshot, even after failure/disconnect. It includes application version, selected endpoint/profile values, attempted query writes, raw controller responses, transport errors and close events with UTC timestamps. TX is an attempted write, not an acknowledgement. Control characters are escaped for readable logs. The journal retains the latest 512 entries, limits individual messages to 4096 characters with explicit truncation, and reports dropped entries. New Connect replaces the journal. Nothing is uploaded or saved automatically; save before exit and review the file before sharing. No passwords or ambient environment are collected. Cancel in the file dialog writes nothing.

## Simulator Move panel

Connect a Simulator profile, then select Move. Set distance and feed, then use X/Y buttons to rehearse movement inside the configured bed. Simulated +Y is up. Pulse power and duration rehearse a bounded pulse, limited to 5% and 500 ms; Stop ends it early. The timer turns simulated power off automatically. Read status reports the same simulated position/S value. The transcript holds the latest rehearsal commands; these never enter a serial/TCP transport. Disconnect ends the pulse and disables manual controls.

This is a control rehearsal, not physical execution or a burn prediction. Jog positions update instantly; acceleration and real controller timing are not modeled. Guided GRBL Move/pulse is separate from rehearsal; homing and reviewed document jobs are available in Laser. The advanced Console can send physical state-changing commands separately.

## Air assist

Each layer has an Air assist on/off checkbox. The state is saved and follows its objects when the layer is reordered. Cut-plan segments carry the requested state; travel segments do not. The device profile records whether its controller has a configured air-assist output. Choose M8 or M7 in Devices for the wired air-assist output (M8 is the default for existing profiles). GRBL export emits the selected command for air on and M9 for off and rejects enabled air requests when the profile does not support them. The layer UI does not actuate air; enabled manual Console commands can do so.

## Trace an image

Select an image or its image layer, then choose Tools / Trace image… or the Trace image icon on the left. The dialog shows the adjusted grayscale source with pink vector contours. Threshold determines which eight-bit tone samples are foreground; Invert changes polarity. Existing image-layer brightness, contrast and gamma are used, but engraving dithering is ignored. The image layer's engraving settings and original embedded bytes are not changed by previewing a trace.

The controls are intended for photographs as well as clean artwork. Each slider has a numeric field. Start with a moderate resolution and adjust the following while watching the pink contours:

- Cutoff excludes tones darker than its value; Threshold excludes tones at or above its value. Both use brightness from 0 (black) to 255 (white). The retained range is Cutoff inclusive, Threshold exclusive. Raising Cutoff can remove a black background; lowering Threshold keeps darker features.
- Ignore less than removes foreground components smaller than the given sampled-pixel count. Diagonal-only contacts are separate components. This is an area in sampled pixels, not millimetres; holes are retained.
- Noise smoothing applies a Gaussian blur before detecting foreground. Increase it to suppress photographic grain; excessive smoothing loses fine detail.
- Outline smoothness rounds the resulting polygon corners using sampled straight segments. Optimize tolerance reduces vertices. These are independent operations, measured in sample pixels, and do not produce Bézier curves.
- Sketch / local contrast finds tones darker than their local neighborhood and can help with uneven illumination. It uses Sketch contrast and Sketch radius; Cutoff and Threshold are disabled in this mode. Higher contrast retains stronger dark features. It traces the boundaries of those features, not their centerlines.
- Max samples / axis ranges from 64 to 1024, retaining aspect ratio. Higher resolution increases detail, noise and work. It is independent of engraving DPI and changes the physical size represented by every sample-pixel setting.

Live preview always recalculates automatically, starting 150 ms after a parameter change and cancelling obsolete work. Both sliders and numeric values trigger updates; there is no Update button or manual-preview mode. Create vector layer remains disabled until a current nonempty result is available. The footer reports original/refined vertex counts, contours and removed components. Delicate contours are retained if refinement would collapse them or change detected crossings/nesting; if a work limit is reached, the entire original outline is retained with an explanation. Inspect the result before creating vectors.

Wheel zoom inspects detail; middle drag pans; Fit preview or a middle double-click restores the view. Fade image, Show threshold mask and Show vertices affect only the preview. Vertex markers are limited to results with at most 5000 points. Closing or Cancel leaves the project unchanged. Tuning is temporary to this dialog; the created geometry is stored in the project.

Create vector layer adds one compound closed path to a new named vector layer, selects it in Nodes mode, and disables output on the original image layer to avoid engraving both automatically. The new layer uses default Line settings (1200 mm/min, 20% power); configure its speed, power, air and mode as needed. The source remains visible and embedded unless Remove source image is checked. That option removes only the project object, never the original file; an empty source layer is retained. Creation, optional source removal and source-output changes form one undo step. Move/reorder/configure the new layer like any other, and edit its vertices or mirror/copy its path. Line mode follows both outer and hole contours; Fill uses their even-odd interior.

This is an independent pixel-edge outline tracer with optional polyline refinement. It does not match LightBurn's algorithms or parameter scale, fit curves, find centerlines, or offer region cropping. Limits are 200000 boundary edges, 100000 result vertices and 10000 contours; excessive detail fails explicitly. Refinement uses a separate bounded work allowance and retains unrefined geometry when it cannot finish its checks. Trace work runs in the background, cancels when the dialog closes, rejects changed source documents and never contacts a laser.

Try samples/photo-tracing.lcraft for an actual photograph. The source is NASA's Apollo 17 Blue Marble; see samples/PHOTO-CREDITS.md for attribution and usage information. A useful starting point is Cutoff 20, Threshold 160, Ignore less than 8, Noise smoothing 0.8, Outline smoothness 0.5, Optimize 0.7 and 512 samples. These are a starting point for this photograph, not calibrated laser settings. Review composition, cleanup, layer power/speed and output preview for each job. samples/trace-outlines.lcraft remains a generated clean-shape fixture. For its original four-contour, 242-vertex result, use 256 samples, threshold 128, minimum area 2 and zero noise/smoothness/optimize.

## Draw and edit vectors

### Join open endpoints

Select exactly two open contours on the same layer and choose Tools / Join open endpoints…. They may be two separate path objects or two contours in one compound path. For more complex selections, separate the paths first; break closed contours before joining. The dialog chooses the closest pair among the four endpoint combinations and reverses traversal as needed. Equal-distance ties keep the original traversal when possible. There is no automatic multi-path chaining or manual endpoint-pair picker yet.

Maximum gap is in millimetres, defaults to 0.1 and accepts 0–20000. A zero limit accepts exactly coincident endpoints. Larger values permit a greater geometry change; the result must still fit the normal project/object limits. Out-of-range gaps and invalid selections disable Join paths and leave the document unchanged. The dialog offers two methods:

- Merge endpoints at midpoint moves each chosen endpoint halfway across the gap and replaces the pair with one vertex. Adjacent segments change; their total length need not stay the same.
- Bridge gap with a cut segment retains the original endpoints and adds a laser-on segment between them, using the layer's cut settings. For coincident endpoints there is no extra segment. This differs from Combine, which leaves disconnected contours separated by off-power travel.

Review the reported gap, movement/added-length summary and drawing: dashed gray is original geometry, cyan is the proposed path, and orange marks the original endpoints. Nothing changes until Join paths. Cancel leaves the document untouched. The result is one open contour and stays open even if its remaining outer endpoints coincide; closing is a separate edit. The earliest selected object in document order keeps its identity/layer and position in object order; the other selected object is removed. Unselected objects remain unchanged. Joining is one undo step, and the resulting vertices are editable in Nodes mode.

Try samples/endpoint-joining.lcraft: Ctrl+A selects both paths; their gap is approximately 0.4472136 mm, so the default 0.1 limit rejects it. Set the maximum to 1 mm to inspect either method. Use Preview after applying; no homing, motion or laser firing is performed by this editing workflow. Joining does not weld intersections, fit curves or guarantee a simple nonintersecting contour.

### Separate and combine path objects

A photo trace is initially one compound path containing many contours. Select it and choose Tools / Separate selected paths to make each contour an independent path object. All resulting objects are selected and retain their layer. Click an individual region in Select mode (or use Ctrl-click to adjust selection), then assign it to another vector layer as needed. You can give those layers different speeds/powers and reorder them. The first contour keeps the original object's identity; other contours receive new identities. Each separation is one undo step. Existing single-contour paths in a mixed selection stay unchanged.

Tools / Combine selected paths makes selected path objects into one compound object, preserving their contour order from the document, open/closed state and world geometry. All selected paths must already be on the same layer so their cut settings are preserved. Combining does not weld overlaps, join endpoints, or create connecting laser-on segments. Disconnected contours remain separated by off-power travel in Line output. It is also one undo step.

Both operations accept paths only: convert rectangles/ellipses to paths first, or trace images. Separation refuses a contour with no extent that cannot be represented as its own object; combining/separation also respect object/contour/vertex limits. Failures leave the project unchanged. Same-layer Fill retains the even-odd rule across contours/objects, including holes. Assigning a separated hole to another layer can change the filled result; inspect Preview after reorganizing regions. This is contour separation, not automatic recognition of semantic photographic objects.

Nodes mode supports manual cleanup of traced photographs and imported polylines. Click a path to select it, then click a square vertex: the active vertex is orange, and the inspector shows its contour/node number. Clicking alone does not move geometry. Drag beyond the small movement threshold to move the vertex; snapping applies to the movement and preserves the grab offset. Each completed drag is one undo step.

- Double-click a segment of the selected path to insert a node at the nearest point on that segment. This point stays on the segment even when grid snapping is enabled.
- Insert (while the canvas has focus), or Tools / Insert node after selected, inserts a midpoint on the following segment. Closed contours include the last-to-first segment. An open contour's last node has no following segment.
- Delete in Nodes mode, or Tools / Delete selected node, removes only the active node and reconnects its neighbors. Closed contours must keep at least three nodes and open contours two; invalid edits leave the original intact and show a message. Edit / Delete and the toolbar's Delete button still remove whole selected objects.
- Tools / Break at selected node opens a closed contour at that point, retaining every segment and making two independent endpoints at the same position. On an open contour, an interior node splits it into two contours sharing that position; selecting an endpoint cannot split it. The pieces remain in one path object and on the same layer. Fill output requires closed contours, so close the path or use Line mode after breaking.
- Tools / Remove selected contour removes the entire contour containing the active node. This can remove small regions or holes from a photo trace. Other contours remain unchanged. The last contour cannot be removed this way; use Edit / Delete for the whole object.

Insert, remove, break and contour removal each support Undo/Redo. After deletion/breaking, click a node again before another node operation. Only a node belonging to the current selected, visible and unchanged path can be edited. These are straight-polyline operations; curve handles, joining separate objects and separating compound contours into objects remain planned. Removing nodes/holes can change the burned area; inspect the output preview after cleanup.

Lines creates straight vector paths: click vertices, then Enter or double-click to finish an open path. C or clicking the first vertex closes a contour with at least three vertices. Backspace removes the last draft vertex; Escape cancels the draft. Switching tools cancels unfinished drawing. A draft has at most 10000 vertices. Drawing is restricted to the bed and commits as one undo step.

Nodes selects a path near its outline. Its square vertices can be dragged; releasing commits one undo step. Tools / Convert selected to paths converts rectangles to four corners and ellipses to 128 straight segments. This conversion is undoable, retains layer/identity, and cannot convert images. Tools / Close selected paths closes every contour in selected paths; each needs at least three vertices. Curve handles and vertex insertion/deletion/join/split are not implemented yet. Select still moves whole objects; numerical resizing, copy, layer assignment and mirroring also apply to paths.

Open and closed paths can be cut in Line mode. Fill requires every contour to be closed and uses the even-odd rule across shapes/contours, preserving holes independent of contour direction. Unconnected contours are separated by laser-off travel. Horizontal or vertical paths can have zero height or width; numeric scaling cannot create a missing extent, so move a vertex with Nodes to change their direction. Path files have limits of 100000 vertices per object, 200000 per project and 10000 contours per object. Dense fill checks an intersection-work budget before scanning. Imported Bézier curves become polylines; native Bézier handles and SVG arcs remain planned.

Try samples/paths-and-nodes.lcraft for compound fill, a polyline and a horizontal line. samples/linear-paths.svg exercises supported straight-path SVG import. Imported styles are not applied; layer settings govern output. SVG path imports use SVG user units and the root viewBox mapping. SVG exports straight contours with M/L/Z; native files retain open/closed topology and normalized immutable vertices.

Choose Rectangle or Ellipse and drag. Select clicks or moves an object. Ctrl-click adds/removes selection; Ctrl+A selects visible objects. Line shapes are selected near their outlines so a surrounding frame does not intercept an image inside it. Dragging a selected object moves the selection. Enter X, Y, width and height at the top, then Apply. Multi-object sizing scales their combined bounds, in millimetres.

Wheel zooms; middle-drag pans; Fit workspace resets the view. Snap rounds to 1 mm. Ctrl+Z/ Ctrl+Y undo/redo. Ctrl+C copies, Ctrl+V pastes, Ctrl+D duplicates. The internal artwork clipboard is separate from the Windows graphics clipboard. Paste offsets 5 mm and retains layer colors; target vector layers keep existing settings. Delete removes selected objects when the canvas is focused; Escape deselects/cancels. Arrange provides alignment, flips and Center on bed.

## Vector preview and playback

Images on the design canvas now show their monochrome preparation, retaining the layer color only on the border. Source color bytes remain embedded for nondestructive editing and SVG export. Canvas previews are bounded to 800 samples on the longest edge and may differ in dot detail from the full output-resolution samples in Image settings. Changing tone/mode/interval invalidates this background-generated display; mirroring also mirrors the displayed preparation. Image settings includes Stucki, Jarvis and Atkinson in addition to Threshold, Floyd-Steinberg, Ordered Bayer and Grayscale. These are independent implementations, not claims of pixel-identical LightBurn output.

Preview hides the editing artwork and shows the planned output on a white bed. Cutting marks use black with opacity proportional to commanded power; Show travel controls pale dashed off-power movements. Start animates a red beam marker. Playback speed is adjustable from 1× to 100×; Pause holds it and Stop / Return to design restores editing. This is an ideal path/power visualization, not a material-specific darkness or thermal model.

Preview plans enabled layers in list order. Line follows rectangles and approximates ellipses with 128 segments. Fill scans horizontally with the even-odd rule, leaving nested holes. Passes repeat their layer. Grey dashed paths are travel; black marks are cutting. Cut selected graphics limits the plan to selected objects.

Preview playback remains offline; the separate Review & Run workflow sends a physical job, with realtime pause/abort. Playback defaults to 10 times ideal time and can be adjusted. Edits, layer reordering, selected-only scope changes or document switches invalidate the old plan. Frame preview checks bed bounds and fits the viewport; it does not move a machine. Estimates assume constant layer speed and 6000 mm/min inter-path travel, without acceleration or material effects. Power levels are planning requests; no physical burn is simulated. Preview generation runs in the background and Stop cancels it. Edits or scope changes cancel/discard stale work. Dense plans are limited to 100000 fill rows, 200000 segments, 16000 samples per axis and 4 million samples per image, 8 million raster cells including repeated passes per job, and a bounded vector intersection-work budget. Increase interval or reduce passes for dense plans. Beyond 25000 segments the canvas samples paths for display; complete paths still drive timing and playback. High-resolution large-photo planning needs further optimization.

## Files and SVG

Save G-code creates an offline GRBL 1.1 laser-mode file from enabled layers (or Cut selected graphics). Select the intended device profile first. The exporter uses its bed dimensions, corner origin, S-value maximum and configured air-output capability; it supports only the GRBL family for now. Bottom origins reflect Y and right origins reflect X around that bed. Set the controller work zero to the chosen bed corner and match firmware $30 to the S-value maximum. Firmware must already have $32=1; export never changes firmware settings. Files use millimetres, absolute work coordinates, units-per-minute feed, M4 dynamic power, explicit S0 travel, optional M8/M7 air, and final M5/M9. Feed-controlled off spans retain raster overscan speed. It adds an initial laser-off rapid to the plan start, but does not home or return home. Bounds, continuity, finite feeds/powers and nonempty plans are validated. The app does not run or transmit saved programs. Manual Console lines are separate; physical/controller-specific qualification remains unfinished.

New opens a document tab. Save / Ctrl+S persists .lcraft; Save as creates another file. A tab dot/title asterisk marks unsaved work. File / Close project saves modified work first; canceling save keeps it open. Closing the entire window asks before discarding changes. A .lcraft path can also be supplied as a startup argument.

SVG import supports untransformed numeric rectangles, circles and ellipses, root mm/cm/in/px dimensions (96 DPI pixels) and uniform viewBox scaling. SVG paths support absolute/relative M/L/H/V/Z, cubic C/S and quadratic Q/T commands, repeated coordinate sets and compound contours; line, polyline and polygon elements are supported too. Smooth commands reflect the preceding compatible curve control point and reset after other command types. SVG arcs (A/a), CSS styles, transforms, rounded rectangles and unsupported elements reject the entire import. This is a geometry importer: paint attributes, visibility and source layer colors are not applied; LaserCraft layers govern output.

After choosing a file, SVG import options asks for Curve tolerance in millimetres (0.001–1, default 0.05). Cubic/quadratic curves are adaptively divided into straight segments after unit/viewBox mapping. A smaller tolerance retains more detail and creates more editable vertices. The original curve controls are discarded: native saves and SVG exports retain the resulting polylines, not editable Bézier handles. Later resizing scales the approximation as well; the import-time tolerance is not recalculated. This option affects Bézier paths, not the existing fixed-segment ellipse planner. Fine gaps/intersections can change when approximated, so inspect the resulting Preview.

Import runs in the background. Cancel before/during processing leaves the document unchanged; a changed destination document/layer invalidates installation. Geometry goes to the active vector layer, or a new vector layer if an image layer was active. Successful imports select the new objects and form one undo step. Failures do not partially import earlier shapes. The importer limits input to 4 MB, 300000 tokens/path, 100000 vertices/path, 10000 contours/path, 200000 subdivision steps/path and subdivision depth 24; project-wide expansion is checked after each object against 200000 vertices. A tolerance that cannot be met within these limits fails explicitly. Move-only or wholly zero-extent paths remain unsupported. Full SVG and additional formats remain planned.

Try samples/bezier-curves.svg for cubic/smooth-cubic, quadratic/smooth-quadratic and a closed cubic loop. Import at 0.025 mm to match the checked desktop example. Use Nodes to edit the resulting line vertices, and Save as .lcraft to retain layer settings and editable polyline geometry. SVG export also retains embedded original raster sources; prepared raster settings remain in .lcraft.

Try samples/raster-engraving.lcraft for a working mixed raster/vector preview, samples/layers-and-image.lcraft for the image/layer workflow, samples/studio-demo.lcraft for nested vector fill, and samples/basic-shapes.svg for supported SVG import. Sample settings are illustrative, not material recommendations.

## Appearance, source and remaining work

Window / Light / dark switches the persisted theme. Help is copied from docs/help/Help.md at build time. LaserCraft's original source is MIT-licensed; third-party packages retain their own licenses. No LightBurn source or protected assets are used.

Full parity remains unfinished: native Bézier editing, advanced text/shaping, advanced node operations, curve-fitted and centerline tracing, booleans, additional raster algorithms and high-resolution optimization, advanced imports, real docking, cameras, rotary, materials, AI and advanced job placement remain planned. Console supports single-line queries and explicitly enabled writes; macros remain planned; initial reviewed physical streaming is implemented. Disabled commands identify unimplemented capabilities. The feature matrix and progress record distinguish tested behavior from planned work.

Document placement restriction in 0.25: Home must succeed in the current connection before document output. Reconnect, job reset or custom console writes invalidate that evidence. This first streaming mode requires a homed negative machine range: X from -profile width to 0, Y from -profile height to 0. Preflight checks the entire translated footprint against those ranges. After homing near machine zero, jog sufficiently inside the bed before running a job extending +X/+Y. Controllers configured for positive machine ranges are not supported by this mode yet. These checks do not prove physical calibration or absence of fixtures/obstructions.

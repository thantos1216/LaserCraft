# Photograph tracing reference and evidence

2026-11-08. Goal: make tracing useful for photographic noise and uneven illumination, retaining editable vector layers and the user's layer workflow. This is a partial milestone, not a complete LightBurn reconstruction.

The public [LightBurn 2.2 Trace Image reference](https://docs.lightburnsoftware.com/2.2/Reference/TraceImage/) describes lower/upper brightness controls, small-area removal, smoothing, node optimization, sketch tracing, preview navigation and boundary selection. The supplied screenshots also show these control families. Read-only UI observation of installed LightBurn 1.3.01 with NASA's Blue Marble photograph confirmed Cutoff 0, Threshold 128, Ignore less than 2, Smoothness 1, Optimize 0.2, Sketch Trace, Fade Image, Show Points and Clear Boundary. This observed control presence/defaults; it did not establish the proprietary algorithm, numeric equivalence or 2.2 execution behavior.

See [REA findings](rea-findings.md#docker-integration-08) for coverage, paths and unavailable providers. Neither result establishes tracing behavior. No proprietary pseudocode, executable payloads, icons or algorithms were copied into LaserCraft.

LaserCraft independently implements Gaussian prefiltering, explicit brightness-range thresholding, neighborhood-mean contrast selection, four-connected component filtering, pixel boundaries, Ramer–Douglas–Peucker simplification and bounded polyline corner rounding. Parameters use sample pixels and original LaserCraft defaults; LightBurn's curve-based Smoothness scale is not reproduced. Crossings, winding, collapse and nesting guards retain original contours or all original geometry when checks are inconclusive. Their behavior is tested but is not a universal topology or appearance guarantee for arbitrary photographs.

The NASA photograph is a real-image fixture with [separate provenance](../../samples/PHOTO-CREDITS.md). One image plus synthetic illumination/noise and exhaustive small binary masks provides regression evidence, not general photo-quality certification. Missing: Bézier fitting, centerlines, trace-region selection, presets and broader portrait/line-art/document/material qualification. Continue public-reference and controlled UI comparisons for those questions rather than inferring features from binary strings or inventory alone.

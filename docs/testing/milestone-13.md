# Milestone 0.13 validation

Local Release build: zero warnings/errors. All 193 tests pass (187 unit, 6 native/file integration). Original implementation follows the command semantics in [W3C SVG 2 paths](https://www.w3.org/TR/SVG2/paths.html#PathDataCubicBezierCommands). This work uses a public interchange specification; no new LightBurn binary analysis or proprietary algorithm/code was needed.

The new SvgPaths parser replaces SvgLinearPaths, with existing callers migrated. Cubic C/S and quadratic Q/T commands, relative coordinates and repeated parameter sets are supported. Quadratics convert exactly to cubic controls before adaptive De Casteljau subdivision in mapped millimetres. A segment is accepted only when both controls lie within the requested distance of its finite chord; this also catches collinear overshoot. Nonfinite calculations, work/depth/vertex limits fail instead of accepting an unqualified approximation. This is floating-point polyline import, not preserved curve geometry or full SVG conformance.

New domain tests independently evaluate 1001 points on representative cubic/quadratic curves against the imported segments; check tighter tolerances, unit/viewBox equivalence, smooth reflection/reset after incompatible commands, repeated relative curves, loops/backtracking, malformed/unsupported commands, extreme coordinates, invalid tolerance, cancellation and aggregate curve-expansion limits. Prior tests now use the owning SvgPaths parser; former unsupported-curve fixtures were replaced with malformed curves or unsupported arcs rather than deleted.

File integration imports the original samples/bezier-curves.svg fixture at 0.025 mm, verifies open/closed topology and detail, builds Line/Fill plans, exports offline GRBL with final laser/air-off commands, reimports exported SVG polylines and round-trips native geometry/cut length. No hardware was contacted.

Release desktop checks: Cancel in import options leaves the clean empty project unchanged. Importing the fixture at 0.025 mm adds and selects three paths with recognizable curves. Preview reports 387 segments, 799.3 mm cut length and 44.0 s ideal duration. One Undo restores zero objects and the clean title. No source file was overwritten. Cancellation during active heavy work, stale-destination rejection, image-layer fallback and file-access failures have source/domain coverage where applicable, but were not separately exercised through the desktop UI in this milestone.

Limits: no A/a arcs, transforms, CSS styles, source paint/visibility interpretation, editable Bézier handles or native curve retention. Scaling after import scales approximation error; export writes polylines. Tolerance is 0.001–1 mm; per-path tokens/vertices/contours/subdivision work/depth and aggregate project expansion are bounded. Degenerate/move-only subpaths can reject otherwise renderable SVG files. Full file-format interoperability, curve topology/material qualification and physical output remain unfinished.

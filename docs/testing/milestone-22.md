# Milestone 0.22 validation

2026-11-10. Guided GRBL control qualification.

- Release suite: 341 unit + 12 integration tests pass. Cases cover permissions, numeric limits, firmware identity/family, Idle gating, laser-off-before-jog, exact units/incremental frames, reported power-setting mismatch/omission/duplicates, pulse/off in one write, shared-gate serialization, cancellation/pre-cancellation, disconnect/queued cancellation, alarms/restarts/errors and reconnect-after-uncertainty. Existing console regressions pass after extracting its owning exchange loop for reuse.
- Public TransportFactory/GrblMonitor TCP loopback verifies exact bytes for identity, status, M5, one X jog, settings, pulse/dwell/off, realtime 0x85 and another M5. Server replies are fragmented bytewise. No physical hardware is involved; serial uses the same Latin-1 byte mapping but no physical COM test was performed.
- Desktop development publish: disconnected Move controls disabled; connected only built-in Simulator, clicked X+ once (X1), pulse test reported S10/100 ms then S0/0 ms with final M5 in rehearsal transcript. Disconnect disabled controls. Physical permissions remained disabled for Simulator. Guided hardware UI controls have not been exercised against a desktop-attached real or fake serial device; their public application API is tested with scripted/TCP peers.
- Protocol basis: official GRBL 1.1 jogging/laser-mode references linked in Help. Original implementation; REA/LightBurn extraction was unnecessary for this public controller protocol. No proprietary code/assets were used. Local TCP does not qualify an Attzr controller or physical USB/optical timing.
- Pulse duration is nominal dwell, not measured or guaranteed shutdown. Partial transport/controller failure can prevent off. M5/jog cancel wait behind current exchanges and are not emergency stops. G1/G94/F60 remain active after pulse. No physical machine operations were performed. Homing, full program streaming and production qualification remain incomplete.
